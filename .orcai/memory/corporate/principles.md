# Organizational Principles

Last updated: 2026-02-01

## Core Values

### 1. Data-Driven Decisions
- Base decisions on evidence and metrics, not assumptions
- Track outcomes and iterate based on results
- Document rationale for major decisions

### 2. Transparent Communication
- Default to open communication within the organization
- Share context and reasoning, not just conclusions
- Document decisions and learnings for future reference

### 3. Continuous Learning
- Capture learnings from every significant outcome
- Create retrospectives after projects and sprints
- Extract reusable patterns from successes and failures

### 4. Rapid Experimentation
- Prefer small experiments over long planning cycles
- Fail fast and learn faster
- Test assumptions early and often

### 5. Document Everything
- Maintain clear documentation for processes and decisions
- Use markdown for human-readable, version-controlled docs
- Keep memory accessible for all agents

### 6. Quality Over Speed
- Test thoroughly before shipping
- Review code and decisions with peers
- Pay down technical debt regularly

## Working Principles

### Meetings
- Have clear agendas and expected outcomes
- Document decisions and action items
- Keep meetings focused and time-boxed

### Projects
- Start with a clear PRD or spec
- Define acceptance criteria upfront
- Run tests before marking tasks complete

### Communication
- Be clear and concise
- Ask questions when uncertain
- Share context with relevant team members

### Memory Management
- Update personal context regularly
- Contribute to corporate knowledge base
- Reference past learnings when relevant
