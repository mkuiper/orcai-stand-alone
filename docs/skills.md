# Skills

Skills are local instruction sets that Orcai can load on demand.

## Add a new skill
1. Create a folder under `.opencode/skill/<skill-name>/`.
2. Add a `SKILL.md` file with front matter:

```
---
name: my-skill
description: short description of when to use it
---

Skill instructions go here.
```

3. Keep the skill focused. Avoid broad, multi-topic instructions.
