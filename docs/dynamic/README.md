# Dynamic Documents

Dynamic documents are living research summaries that Orcai updates on a cadence.

## How to add a new dynamic document
1. Copy `docs/templates/dynamic-document.md` to `docs/dynamic/<topic>.md`.
2. Add the job to `.opencode/research-jobs.md`.
3. Add an initial baseline section and changelog entry.
4. Run a research job and record a run summary.

## Files
- `docs/dynamic/ai-chem-synthesis.md`: example dynamic doc
- `docs/dynamic/changelog.md`: cross-document changelog
