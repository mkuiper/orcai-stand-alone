# Citations & Verification

This defines a simple, consistent citation format and a verification checklist for research updates.

## Citation format
Use numbered references in the document body:
- Inline: `[1]`, `[2]`
- Multiple: `[1][3][4]`

In the **Sources** section, list entries as:
```
[1] Author, "Title", Source/Publisher, Year. URL.
[2] Author(s), "Title", Journal/Conference, Year. DOI/URL.
```

## Verification checklist
- Each new claim has at least one citation.
- Primary sources are preferred; secondary sources are labeled as such.
- Conflicting sources are noted with a brief neutral comparison.
- Dates and version numbers are explicit.
- Any uncertainty is called out in the text.
- The changelog summarizes what changed and why.

## Citation hygiene
- Do not include credentials or private URLs.
- Avoid long quotes; summarize and cite instead.
- Re-check high-impact claims against the primary source.
