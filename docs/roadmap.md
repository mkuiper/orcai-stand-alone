# Orcai Roadmap

This roadmap captures the major themes and milestones for Orcai. It is directional and updated as we learn.

## Themes
- Multi-agent orchestration with clear roles, prompts, and quality gates
- Voice-first workflows that remain optional and accessible
- Research workflows: repeatable literature sweeps, fact checking, and document updates
- Extensible catalogs: skills, agents, tools, and MCP integrations
- Robust repo control and safe automation

## Milestones

### Milestone A: Core UX & Voice (now)
- Stable push-to-talk and talkback with interrupt
- Keybind reliability across popular terminals
- Clear visual indicators for voice state and active voice profile

### Milestone B: Agent System v1
- Canonical agent roles: intake, orchestrator, executor, docs
- Task Brief format and enforcement
- Spec/PRD creation flow and acceptance criteria gating

### Milestone C: Research Workflows
- "Research jobs" that run on a schedule or manually
- Source tracking and citations for document updates
- Versioned dynamic documents with changelog summaries

### Milestone D: Catalogs & Integrations
- Curated skill/agent/tool catalogs stored in-repo
- MCP registry connections and templates
- Provider catalogs for OpenAI, Anthropic, Gemini, etc.

### Milestone E: Repo Control & Automation
- Safe auto-push with approvals and audit trail
- Configurable branch strategies (dev/prod, staging)
- Automated test gating before merge
